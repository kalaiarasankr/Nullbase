# Contributing

Thanks for contributing to NullBase.

## Layout submissions

1. Fork the repository.
2. Add the layout image to `assets/layouts/`.
3. Add metadata to `data/layouts.json`.
4. Test the website locally.
5. Verify the Null's Clash link with Null's Clash installed.
6. Open a pull request.

Only submit layouts and assets you are permitted to share. Do not submit personal information, malicious code, trackers, unrelated links, or material that impersonates Null's Clash/Supercell.

## Code

Prefer dependency-free HTML/CSS/JavaScript where practical. Keep mobile responsiveness and accessibility in mind.
